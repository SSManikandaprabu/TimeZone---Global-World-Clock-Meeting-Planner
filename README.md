# TimeZone - Global World Clock & Meeting Planner

A multi-city world clock and cross-timezone meeting scheduler with visual working hour overlap sliders and UTC offset calculation.

## Features

- Search and pin multiple global cities and time zones to an interactive dashboard
- Real-time synchronized digital clocks displaying local time, date, and UTC offsets
- **Interactive meeting planner slider**: Interactive meeting planner slider: scrub time across 24 hours to find optimal overlapping working hours across continents
- Color-coded availability indicators (Working Hours, Morning/Evening, Sleeping Hours)
- City database covering major global business hubs across America, Europe, Asia, and Australasia
- LocalStorage memory saving your pinned team cities

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Tailwind CSS
- LocalStorage API

## Installation & Setup

This is a standalone, client-side web application. No complex build pipelines, database configurations, or package installations are required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SSManikandaprabu/TimeZone---Global-World-Clock-Meeting-Planner.git
   cd TimeZone---Global-World-Clock-Meeting-Planner
   ```

2. **Run the application:**
   - **Direct Browser Launch**: Double-click `timezone_global_world_clock_meeting_planner.html` to open it directly in any modern web browser (Chrome, Firefox, Safari, Edge).
   - **Or via Local HTTP Server**:
     ```bash
     python -m http.server 8000
     ```
     Then open [http://localhost:8000/timezone_global_world_clock_meeting_planner.html](http://localhost:8000/timezone_global_world_clock_meeting_planner.html) in your browser.

## Usage

1. Launch the application in your browser following the setup instructions above.
2. Interact with the application controls and input fields tailored for TimeZone - Global World Clock & Meeting Planner.
3. Preferences and data are stored locally in your browser's LocalStorage where applicable.
